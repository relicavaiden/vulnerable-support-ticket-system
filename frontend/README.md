# Vulnerable Support Ticket System

## Project Overview

This project is intentionally vulnerable support ticet system built to deomonstrate secure software developement, OWASP Top 10 concepts, backend engineering, authentication, authorization, and security remediation

The application will first be built with intentionally vulnerable patterns, then later secured and documented as a portfolio project.

## Tech Stack

### Frontend
- Next.js
- React
- Typescript
- Tailwind CSS

### Backend
- Flask
- Python

### Database
- SQLite

### Deployment
- AWS, planned for a later phase

## Version 1 Scope

Version 1 will focus on basic support ticket workflow with seeded users

Planened V1 features:
- Seeded requester and resolver users
- Login
- Ticket creation
- Ticket detail view
- Requester follow-up notes
- Resolver notes
- Ticket status updates
- Auto-assignment to a seeded resolver

## Out of Scope for Version 1

- Public user registration
- Admin dashboard
- Ticket deletion
- Ticket search
- Viewing deleted tickets
- Admin-based ticket assignment

## Security Focus

This project will be used to demonstrate and later remediate vulnerablilities such as:

- Broken Access Control (BAC)
- SQL Injection
- Cross-Site Scripting (XSS)
- Authentication and session weaknesses
- Security misconfiguration
